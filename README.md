# CannaPlug 012

Build the CannaPlug premium cannabis dispensary website FRONT-END as a presentation-ready visual prototype.

MASTER BLUEPRINT:
Use the attached visual design system and CannaPlug website UI/UX design image as the primary visual source of truth. The supplied CannaPlug menu and “PLUG BACK” campaign artwork should also guide the brand language, typography, product presentation and visual identity. 

Do not create a generic cannabis ecommerce template. Visually translate the reference into a sophisticated, editorial, premium digital experience.

PHASE 01 = VISUAL PROTOTYPE ONLY.

Do NOT implement:
- Supabase
- Authentication
- Payments
- Real checkout
- Inventory
- CMS
- APIs
- Database architecture
- Real form submission
- Complex ecommerce functionality

Use realistic mock content/data and presentation-only interactions. Structure components cleanly so functionality can be connected in Phase 02.

==================================================
BRAND / ART DIRECTION
==================================================

CannaPlug™ is a premium South African cannabis dispensary.

Brand attributes:
PREMIUM • CURATED • DISCREET • KNOWLEDGEABLE • TRUSTED • COMMUNITY

Visual personality:
Premium lifestyle brand + editorial publication + modern ecommerce.

Avoid:
generic cannabis-store aesthetics, neon green, excessive leaf graphics, clutter, heavy gradients, cheap-looking cards, excessive animations or dark-first design.

Primary message:

QUALITY CANNABIS.
REAL PEOPLE.

Supporting messaging:

“Premium products. Expert guidance. A better experience.”

“Good plants. Great people.”

Use confident, polished, contemporary copy throughout. Never use Lorem Ipsum or generic placeholder copy.

==================================================
DESIGN SYSTEM
==================================================

Colours:

Forest Green — #0B3D20
Leaf Green — #16A34A
Charcoal — #111111
Cream — #F8FAF8
White — #FFFFFF
Gold — #D4AF37
Sage — #A7B89F
Stone — #E5E7EB
Slate — #6B7280

Use Cream/White as the dominant interface.

Forest Green = primary brand/CTA/navigation/footer.
Leaf Green = active states and highlights.
Gold = restrained premium accent.

Build all colours as CSS variables/design tokens so a future dark mode can be added without restructuring the UI.

Typography:
Montserrat Bold/SemiBold for headlines, navigation and product titles.
Inter Regular/Medium for body copy and supporting UI.

Use strong editorial typography, tight headline line-height and generous whitespace.

==================================================
FLOATING BOTTOM NAV
==================================================

Implement this as the second signature CannaPlug UX pattern.

Create a floating pill-shaped navigation bar fixed near the bottom of the viewport.

Desktop:

HOME | SHOP | [CANNA PLUG LEAF] | EVENTS | NEWSROOM

The central CannaPlug leaf button should be elevated above the bar.

Use:
- Dark green surface
- White icons/text
- Rounded pill geometry
- Soft shadow
- Active state
- Smooth hover/press animation

Mobile:

HOME | SHOP | [LEAF] | EVENTS | ACCOUNT

The floating navigation should feel like a premium mobile command centre, not a conventional bottom tab bar.

It should remain visible but unobtrusive.

==================================================
MOTION
==================================================
